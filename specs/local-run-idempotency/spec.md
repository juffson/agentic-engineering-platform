# 同一次本地派发只执行一次

在一台设备、同一个 Git 公共目录内，派发方可以为一次尝试提供稳定的 Run ID。重复消息必须能找回这次尝试的结果。省略 ID 时，CLI 继续为每次调用创建独立的 Run。

| 验收条件 | 可观察的结果 |
| --- | --- |
| 相同 ID 的两个进程同时执行 | 至多一个进程启动检查。第二个进程返回暂时忙碌（退出码 75），可用 `status` 查看进展。 |
| 成功或失败后的相同派发 | 返回原来的结果和证据，保留原始结束时间。 |
| 同一 ID 改用另一提交或执行配置 | 拒绝复用，原报告仍可查看。候选分支名相同但已移动时，也按不同提交处理。 |
| 本地执行器被终止，未持久化最终结果 | 标记为需要核对，提供工作区和已记录的提交。重复派发不会再次启动执行器、测试或模型。 |
| 离线排查、历史数据 | 通过本地 CLI 查看 JSON。旧版本生成的证据仍可读取，缺少请求身份的历史 Run 不参与重放。 |

本阶段以单机本地文件系统为边界。跨设备所有权、接管仍在运行的子进程和自动恢复属于后续工作。人工确认后可以使用新的 Run ID 开始下一次尝试。

# 单窗口行情聚合按事件标识去重

输入是一批已进入同一聚合窗口的合成事件。一个事件的身份由 `source` 与 `event_id` 共同确定；同一身份再次出现时保留首次记录。不同来源允许使用相同的编号。原型只处理内存中的一个窗口，输入数量为非负整数。

| 验收 | 输入 | 预期（数量，有效事件数） |
| --- | --- | --- |
| AC-1 正常 | A 来源的 E1(10)、E2(5) | 15，2 |
| AC-2 重复投递 | E1(10)、E2(5)、E1(10)，均来自 A | 15，2 |
| AC-3 内容相同但身份不同 | A 的 E1(10)、E3(10)，相同时间戳 | 20，2 |
| AC-4 跨来源编号 | A 的 E1(10)、B 的 E1(5) | 15，2 |
| AC-5 重复携带不同数量 | A 的 E1(10)、A 的 E1(12) | 10，1 |
| AC-6 空窗口 | 空列表 | 0，0 |

本次允许修改 `examples/marketdata/aggregate.py`。验收脚本及工作流随派发版本固定。迟到事件、跨窗口重算和持久化由后续独立需求定义。

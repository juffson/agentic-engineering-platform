# 多 Agent 共享工程记忆

在使用同一个 Git 公共目录的工作区之间传递决策、交接摘要和待澄清的问题。一次 Run 启用共享记忆后，执行器为每个角色选择上下文，并记录实际传递和新增的记忆 ID。输入规范、检查和批准仍有各自的事实来源。

| 场景 | 验收条件 |
| --- | --- |
| 跨 Worktree 接力 | 在一个工作区写入的仓库约定在另一个关联工作区可读。独立克隆使用独立存储。 |
| 版本边界 | 项目约定可跨任务复用。任务记忆绑定 Task 和 Spec SHA。实现摘要与审查意见只进入对应候选 SHA 的上下文。Spec 级未决问题带有来源提交，可供同一 Spec 的下一轮处理。 |
| 实现与审查 | Codex 产出的摘要经执行器校验范围后写入；Claude 审查同一提交时能收到它，随后写入独立审查摘要。人工批准仍为待处理。 |
| 修订与重试 | 替代记录保留原文；并发替代只有一次成功。相同 Run 重送不增加记忆。无效的结构化输出不应成为共享知识。 |
| 可追溯与容量 | 条目包含来源角色、Run、适用版本和时间。Run 记录各角色的输入及输出 ID。选入提示词的记忆有条数和字节上限。 |
| 数据范围 | 默认关闭自动共享；显式启用后，只传选中的短文本。原始会话、完整审查报告和命令日志不自动加入共享库。 |
